# Métodos Ágeis: Scrum

## Sobre o projeto

Este projeto foi desenvolvido como atividade acadêmica do curso de Análise e Desenvolvimento de Sistemas.

O objetivo é apresentar os principais métodos ágeis utilizados no desenvolvimento de software, com foco no framework Scrum.

## Conteúdo abordado

- Origem do Scrum;
- Características e funcionamento;
- Responsabilidades e eventos;
- Benefícios na gestão de projetos;
- Desafios durante sua aplicação.
